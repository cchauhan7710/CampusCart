# CampusCart - Premier Student Campus Marketplace

CampusCart is a modern, high-performance student-to-student marketplace designed for buying, selling, and trading textbooks, electronics, notes, lab coats, and campus essentials.

## 🚀 Key Features

- **Luxury Dual-Theme Engine**: Smooth off-white light mode and sleek dark mode with active pill toggle.
- **Product Marketplace**: Filterable listings by category, real-time search, price sorting, and single-line responsive layout.
- **Student Profile Dashboard**: Manage listed items, account verification badge, avatar uploads, and personal profile stats.
- **Shopping Cart & Wishlist**: Persistent cart and wishlist drawers with instant badge counters.
- **Lazy Loading & Skeleton Wireframes**: Fast first page loads (<220kB initial bundle) with shimmering skeleton loader components.
- **Secure Authentication**: JWT-based auth with session management, protected routes, and email OTP password resets.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons, Framer Motion, React Hot Toast, Axios
- **Backend**: Node.js, Express, MongoDB (Mongoose), JWT, Bcrypt, Multer, Cloudinary

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/cchauhan7710/CampusCart.git
   cd CampusCart
   ```

2. **Backend Setup**:
   ```bash
   cd Backend
   npm install
   npm start
   ```

3. **Frontend Setup**:
   ```bash
   cd Frontend
   npm install
   npm run dev
   ```
